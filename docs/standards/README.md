# Chuẩn Tài Liệu Và Cách Làm Việc

Thư mục `docs/standards/` chứa các quy ước dùng chung cho toàn repo. Đây là nơi giúp dự án giữ được tính nhất quán khi số lượng tài liệu, service và người tham gia tăng lên.

## Nên đọc theo thứ tự

1. [DOCUMENTATION_STYLE_GUIDE.md](DOCUMENTATION_STYLE_GUIDE.md)
2. [GIT_WORKFLOW.md](GIT_WORKFLOW.md)
3. [COMMIT_CONVENTION.md](COMMIT_CONVENTION.md)
4. [PULL_REQUEST_CHECKLIST.md](PULL_REQUEST_CHECKLIST.md)

## Mục tiêu của khu vực này

- Chuẩn hóa cách viết tài liệu
- Chuẩn hóa cách đặt tên file và thư mục
- Chuẩn hóa quy trình Git cơ bản
- Giảm cảm giác repo bị rối khi mở rộng

## Lưu ý

- Template để GitHub thực sự dùng nên đặt trong `.github/`.
- `docs/standards/` là nơi giải thích quy ước, còn `.github/` là nơi triển khai quy ước đó vào workflow.
