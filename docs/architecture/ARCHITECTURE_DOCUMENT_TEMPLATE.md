# Tên Tài Liệu Kiến Trúc

## 1. Mục tiêu

Tài liệu này dùng để giải thích bài toán hoặc quyết định kiến trúc nào.

## 2. Phạm vi

Nêu rõ tài liệu áp dụng cho:

- toàn hệ thống,
- một nhóm service,
- hay một boundary kỹ thuật cụ thể.

## 3. Bối cảnh

Giải thích vì sao cần tài liệu này và vấn đề đang cần giải quyết là gì.

## 4. Thiết kế hoặc hiện trạng

Mô tả:

- thành phần liên quan,
- luồng chính,
- rule hoặc boundary quan trọng,
- dữ liệu hoặc contract liên quan nếu cần.

## 5. Trade-off

Nêu rõ:

- ưu điểm,
- nhược điểm,
- lý do chọn phương án hiện tại.

## 6. Rủi ro hoặc giới hạn

Nêu rõ điều gì chưa làm, chưa chắc, hoặc chưa production-ready.
